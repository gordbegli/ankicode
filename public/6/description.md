# Reversing a Linked List

Write the template for reversing a linked list iteratively.

## When to Use
- Reversing a linked list in place
- Problems requiring list reversal as a subroutine
- Reordering linked list nodes

## Template Structure
- Track `curr` (current node) and `prev` (previous node)
- Save next node before changing pointer
- Reverse the pointer direction
- Move to next node
