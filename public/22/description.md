# Dynamic Programming: Top-Down Memoization

Write the template for top-down dynamic programming with memoization.

## When to Use
- Optimization problems with overlapping subproblems
- Problems with optimal substructure
- When recursive solution has repeated work
- Counting problems

## Template Structure
- Define recursive function with state parameters
- Check base case
- Check memo for cached result
- Compute result using recurrence relation
- Store in memo and return
