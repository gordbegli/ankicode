# Two Pointers: Two Inputs

Write the template for the two pointer technique using two input arrays, exhausting both.

## When to Use
- Merging two sorted arrays
- Comparing elements from two sequences
- Finding common elements
- Problems involving two lists that need simultaneous traversal

## Template Structure
- Initialize pointer `i` for arr1, pointer `j` for arr2
- Process while either array has elements
- Handle remaining elements after one is exhausted
