# Backtracking

Write the template for backtracking algorithms.

## When to Use
- Generating all combinations/permutations
- Constraint satisfaction problems
- Finding all solutions that match criteria
- Problems requiring exhaustive search with pruning

## Template Structure
- Base case: when to add to answer
- Iterate over choices
- Make a choice (modify current state)
- Recurse
- Undo the choice (backtrack)
