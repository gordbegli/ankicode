# AnkiCode  
AnkiCode is a companion to the [LeetCode Crash Course](https://leetcode.com/explore/featured/card/leetcodes-interview-crash-course-data-structures-and-algorithms/) designed to allow users memorize the algorithm Python templates in that course.


## Keyboard Shortcuts  

| Shortcut      | Action         |
|---------------|----------------|
| Cmd + Enter   | Submit         |
| Cmd + ;       | Reveal Answer  |
| Cmd + '       | Next Card      |
