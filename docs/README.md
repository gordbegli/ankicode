# AnkiCode  
AnkiCode makes it easy to memorize the algorithm templates from [LeetCode Crash Course](https://leetcode.com/explore/featured/card/leetcodes-interview-crash-course-data-structures-and-algorithms/).




## Keyboard Shortcuts  

| Shortcut      | Action         |
|---------------|----------------|
| Cmd + Enter   | Submit         |
| Cmd + ;       | Reveal Answer  |
| Cmd + '       | Next Card      |
